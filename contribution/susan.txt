Susan Saji Contributions
========================

Content:
- Database design and management
- Attendance data storage and retrieval

Description:
Susan Saji designed and managed the database structure. She handled storage and retrieval of attendance data, including schema design and efficient querying.

Files and work (main project)
-----------------------------
- database/schema.sql
  MySQL schema: databases, students, faculty, admin, courses, timetable, attendance
  (hour1–hour9), camera_health_log seed data, and initial reference inserts.

- attendance_service.py
  Attendance business logic on top of MySQL: ensuring attendance rows, period updates,
  class-level marking from detections, camera health logging, faculty upload day flags,
  manual upload eligibility, and related CREATE TABLE safeguards for logs.

- app.py (database usage)
  SQL throughout Flask routes: connections, timetable resolution, attendance CRUD, faculty
  mapping, system status queries—wiring HTTP/API layers to the schema Susan defined.

Demo database variant
---------------------
- demo/database/schema_demo.sql
  Separate demo database (Attandance_demo), same core tables plus demo_period_schedule for
  wall-clock period metadata aligned with the demo app.

- demo/attendance_service.py
  Demo copy pointed at Attandance_demo; same attendance/storage patterns as production.
