Files and work (main project)
-----------------------------
Dataset pipeline / preprocessing
- preprocessing/align.py
  Face alignment (e.g. MTCNN path) before embedding-quality crops.

- preprocessing/augment_data.py
  Data augmentation for more robust training or enrollment images.

- preprocessing/capture_image.py
  Utilities for capturing or organizing raw images for the dataset.

- preprocessing/dataset_cleaner.py
  Cleaning and quality control on collected face images.

- preprocessing/preprocessing_images.py
  General image prep steps (resize, normalize, batch handling) for the ML pipeline.

Migration / tooling
- migrate_embeddings.py
  Migrates stored embeddings (e.g. from .npz) into MySQL for runtime use.

- resolve_conflicts.py
  Helper tooling for resolving data or merge conflicts in project assets or metadata.

Documentation and dependencies
- project explanation.txt
  In-depth project documentation: architecture, flows, configuration, and behaviour.

- requirements.txt
  Python dependency list for reproducing the environment and running tests.
